# 本地中文语音视频助手

无需填写 Key 或模型地址。此版本不调用 OpenAI API，不消耗 API 额度。

## 使用

在当前这台 Mac 上双击 `启动midea本地助手.command`，打开 `http://127.0.0.1:8765`。网页会自动连接本地模型。

- 点击“和 midea 直接说话”进入持续中文语音对话。
- 点击“实时视频”，再点击“开始实时通话”，允许摄像头和麦克风。
- 停顿约一秒会自动提交一轮语音。识别、视觉理解和回答需要处理时间，并非零延迟。
- 摄像头持续预览，每两秒自动更新一张画面，发问时使用最近画面；不是完整视频逐帧推理。
- 小熊回答时可以打断。自动回声消除依赖浏览器与设备，戴耳机效果更稳。
- “结束通话”、关闭页面或切到后台即停止当前浏览器的麦克风与摄像头。
- 中文文字、语音和画面由这台 Mac 处理。若通过手机访问，媒体会经加密连接传回这台电脑。

## 模型与语音

- [Qwen3.5 2B Q4_K_M](https://ollama.com/library/qwen3.5:2b-q4_K_M)：本地中文对话、图片理解，约1.9GB。
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) 的 Whisper base 多语种模型：本地中文识别。
- macOS Tingting 中文女声：本地语音合成。
- [Ollama](https://docs.ollama.com/macos) 运行于 Mac Metal GPU，关闭云端模型功能。

## 原二维码与手机

原 GitHub Pages 网页可在当前临时连接在线时自动进入本地模型网页。临时连接依赖本机的 Cloudflare Quick Tunnel，电脑或隧道停止后，原网址回退为演示页。重建临时隧道会产生新地址，需同步更新 GitHub 的 `local-runtime.json`。它不是永久云服务。

本地直接使用不依赖这个临时连接，运行启动文件即可。不要把 API 密钥、私密环境文件或系统模型配置上传到仓库。

## 数据与资料范围

网页仅提供有限的已核查 Midea 美国资料示例；本地模型不进行实时联网检索。具体型号资料缺失时应要求用户提供完整型号，并指向官方支持；不能把示例型号的参数套用其他家电。视觉模型可能误读铭牌和细小错误码，请核对原件。

服务只绑定本机127.0.0.1，手机入口经临时 HTTPS 隧道。只暴露助手页面和受限接口，不提供本地文件浏览、Shell、任意URL抓取或密钥读取。上传媒体在内存处理，合成音频临时文件使用后删除。每分钟模型请求有上限。此版本供少量个人体验，不是公开商业服务。

## 安装位置

运行程序和模型保存在当前项目 `work/runtime` 与 `work/models`。Ollama 的本机身份文件保存在其标准 `~/.ollama` 配置目录。Python依赖列在 `backend/requirements-local.txt`。
