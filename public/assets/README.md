# 用户图片接入位置

当前聊天图片尚未作为可读取文件提供，不能将聊天预览当作本地文件。
取得原图后原样放入（无需重新生成或修改原图）：

- products.jpg：白底全系列产品合照（960×399）
- laundry.jpg：上下叠放洗护设备场景（1280×720）
- living.jpg：开放式客餐厅全屋家电场景（960×536）
- kitchen.jpg：原木厨房冰箱及烹饪设备场景（1280×720）

也支持同名 .png / .webp / .jpeg。运行 npm run build 会检测原图、生成 media-manifest.js 并将图片复制到 dist/assets。没有图片时不请求不存在的文件，不显示伪造照片；保留当前产品示意图，场景区使用纯文案布局。图片未齐全不算完成图片替换。
