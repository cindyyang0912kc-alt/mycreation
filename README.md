# 马来西亚中文家电门店 H5 Demo

使用用户提供的东芝家电原图，采用白底、红色重点、无衬线字体和简洁产品排版。无需支付或 WhatsApp 账号即可体验整个顾客、店长、导购流程。

## 启动与构建

```sh
npm ci
npm run build
npm start
```

Node.js 24+，默认端口 3000，可使用 PORT 覆盖。构建后的 dist/ 是完整静态 H5，支持 GitHub Pages 的 /mycreation/ 子目录。

## 原图与产品

四张 JPG 来自用户上传的 原图.zip：全系列产品合照、客餐厅、洗护区和厨房。文件原样保存在 public/assets/，未重新编码、未重绘或生成替代图片。originals.json 保存原件 SHA-256，测试会核对字节完整性。

商品卡片、详情及对比界面用 CSS 视口展示产品合照中的对应设备，原图文件本身不变。首页与场景区展示完整家居照片。页面不再使用 SVG 产品或绘制的厨房场景。

8 件展示商品按照片中的家电外观分类：四门冰箱、滚筒洗衣机、壁挂空调、洗碗机、嵌入式烹饪设备、台式烹饪设备、立式饮水设备、空气设备。未从图片推断真实型号、容量、尺寸、能效或保修，未提供的资料统一标为“待门店确认”。DEMO 编号是展示编码；MYR 价格用于演示，不是官方报价。

字体为英文 Arial / Helvetica 与中文 Noto Sans CJK / PingFang SC / Microsoft YaHei 等无衬线系统字体；没有声称使用东芝专有字体。站点是风格演示，并非东芝官方站点。

## 体验流程

1. 在商城浏览场景、搜索型号或文案关键词，按品类筛选产品。
2. 打开产品查看外观说明、场景卖点及参数资料。
3. 选择 2–3 件商品进行对比，可移除、清空、仅显示不同参数。
4. 加入购物车，用预填的虚构马来西亚收货信息提交订单。
5. 选择模拟 FPX、DuitNow QR 或电子钱包，体验支付成功、失败、取消及重试。
6. 在门店订单页面开始配送、确认送达；在我的订单查看同步时间线。
7. 支付成功后自动建立演示会员，导购可设置分群与模拟订阅状态。
8. 创建营销草稿并模拟发送；在消息预览中模拟已读、退订及返回商城。
9. 部署后用门店二维码入口生成当前公开 H5 地址的二维码。

## Demo 边界

所有演示订单、会员及消息都保存在当前浏览器 localStorage，不能跨手机同步。页面明确标注模拟支付和消息，不会扣款、真实配送或发送 WhatsApp。演示角色切换无需登录，正式产品必须接入账户权限。请使用虚构资料。

原 Node/SQLite API 保留用于后续开发，H5 Demo 不调用它。真实后台 API 需要 ADMIN_TOKEN，未配置时禁用。其 data/store.db 与浏览器 Demo 数据相互独立。不要把密钥、.env 或数据库加入静态发布包。

## 验证

```sh
npm test
npm run build
npm run test:e2e
```

6 项 Node 测试：图片原件哈希、模拟支付与会员营销、商品与二维码、后台权限、订单配送、营销草稿。
4 项浏览器测试：手机完整链路、二维码和布局、产品详情搜索及对比、原图资源与 8 个裁切视口，并生成手机与桌面截图。

端到端测试使用 /usr/bin/chromium；其他机器按安装位置调整 playwright.config.js。

## 发布

```sh
npm run publish:pages
```

发布脚本构建 dist/ 并推送当前 GitHub origin 的 gh-pages 分支，不强制推送，不切换当前工作分支。首次由仓库管理员在 Settings → Pages 中选择 Deploy from a branch → gh-pages → / (root) → Save。

分支推送成功不等于公开网站已上线；应确认公开 HTTPS 页面及图片返回正常后再声明公网可用。静态 H5 可部署在任意静态托管平台。

云任务使用现有 /workspace/mycreation 检出，无需另建 worktree。
